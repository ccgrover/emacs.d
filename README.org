Fixing the Dark theme:

The PGTK build (~emacs-pgtk~) uses GTK3, which does not automatically honour
GNOME's ~color-scheme prefer-dark~ setting. Fix it by adding a GTK3 settings
file:

#+begin_src shell
  mkdir -p ~/.config/gtk-3.0
  cat >> ~/.config/gtk-3.0/settings.ini <<'EOF'
  [Settings]
  gtk-application-prefer-dark-theme=1
  EOF
#+end_src

No extra packages required — Adwaita's dark variant is built into GTK3.
